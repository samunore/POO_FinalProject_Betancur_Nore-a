Aplicación de gestión para una tienda de videojuegos, cuyo objetivo principal es permitir el registro de clientes, la administración del catálogo de videojuegos y la creación, modificación y finalización de órdenes de compra.
Inicio del programa
El usuario accede a un menú principal donde puede gestionar clientes, videojuegos u órdenes.
El sistema permite buscar un cliente por cédula o número de celular.
Si no existe, no se puede continuar con la compra.
Si el cliente existe, se le da la opción de iniciar una orden nueva.
Se genera un ID de orden.
Se asocia directamente al cliente.
El usuario puede:
Ver videojuegos disponibles.
Agregar uno a la orden.
Buscar por título o género.
Consultar el precio total.
Finalización de la compra
El usuario puede:
Finalizar la orden: se registra en el historial del cliente y de la tienda.
Cancelar la orden: se descarta y no se guarda.
Consulta de órdenes pasadas
El sistema permite ver el historial de compras del cliente.
